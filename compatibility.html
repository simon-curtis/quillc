Rust compatibility.

Will your project work?
Start with its requirements.

Quill is experimental and is not yet a drop-in replacement for rustc. Supported programs build on Linux x86-64; compatibility with an arbitrary Cargo project has not been established. Read the full target and completion criteria.

      Check these first.

      Platform
      Supported native output is Linux x86-64. Projects that need Windows cannot use Quill’s native backend yet. Target support ↗
      Dependencies
      Selected workspace-local libraries work. General crates.io and Git dependencies remain incomplete, so review the requirements of your dependencies as well as your own code. Dependency support ↗
      Language and libraries
      Quill implements selected Rust forms and library operations. General macro expansion, borrow checking, and standard-library support have substantial gaps. A feature marked partial needs a closer look at the forms your code uses. Find a feature below ↗
      Build workflow
      Selected Cargo binary builds work. Build scripts have limited support; Cargo test and doctest workflows and rustc-compatible library artifacts are not ready. Cargo support ↗

      For a concrete example of what works, see the Catalog Flow workspace and its limits. We do not yet have a reliable project compatibility percentage. Use the feature details below to identify blockers before trying Quill on your code.

      Partial

      Library & runtime

      UTF-8 string literal helper calls

      Available

      The narrow native path passes a string literal to a one-argument &str helper and reads byte length. Empty strings, NULs, and multibyte UTF-8 are covered in documented runtime comparisons.

      Partial

      Partial

      Cargo

      Single binary with workspace libraries

      Available

      The subset command builds one default binary, at most one same-package library, and workspace-local ordinary library dependencies. It emits one combined executable.

      Source notes ↗

      Cargo

      Features and cfg

      Partial

      The subset build, parse, and check commands accept Cargo's --features, --no-default-features, and --all-features selections; selected features and supported target predicates reach source collection and type checking. A supported native build script can emit rustc-cfg. Other directives and complete cfg processing are not implemented.

      Source notes ↗

      Cargo

      External dependencies and build scripts

      Partial

      A supported native build script can emit rustc-cfg directives. External build dependencies, other directives, and broader build-script behavior remain unsupported.

      Source notes ↗

      Cargo

      Multiple binary targets

      Partial

      Builds supported default-member binary targets into an output directory, or selects one with --bin. Every target must still fit Quill’s native subset.

      Source notes ↗

      Cargo

      Cargo artifacts and Rust ABI

      Partial

      Quill can package top-level non-generic functions with i32, u64, and usize signatures in self-contained rlibs that pinned rustc can consume. Rustc emits the wrapper metadata; Quill emits the native function bodies. Structs, generics, modules, dependency graphs, and general Rust ABI compatibility remain unsupported.
